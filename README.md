## 3주차 변경 사항

### 1. 기능 추가 · 개선 (답변 품질과 사용성)

| 변경 | 이유 (2주차 피드백 · 실험에서 나온 문제) | 결과 |
|---|---|---|
| **하이브리드 검색** (BM25 + 임베딩 → RRF) | 의미 검색만으로는 "사업 기간" 같은 키워드형 질문을 놓침 (2주차 모든 설정에서 오답) | 처음으로 정답. 근거 포함률 86%(기준) → **100%** |
| **설정 재선정**: chunk 200 / k 7 / 하이브리드 / 개선 프롬프트 | 테스트 질문을 9개 → 16개로 늘려 다시 실험 | 정답률 94% 유지, 2주차 추천 설정보다 질문당 비용 **11% ↓** |
| **대화 맥락 유지** | "그 기간은 언제부터야?" 같은 후속 질문을 이해 못 함 | 후속 질문을 독립 질문으로 바꿔 검색 (F1: 오답 → 정답) |
| **답변 스트리밍** | 답이 다 만들어질 때까지 빈 화면 | 첫 글자 평균 **1.2초**, 전체 2.6초 (목표 10초) |
| **검색 과정 · 근거 표시**, 예시 질문 버튼, 👍/👎 평가 | 사용자가 답의 근거를 확인하고 바로 시작할 수 있게 | 평가 결과는 운영 현황 · 로그에 집계 |
| 실험용 슬라이더를 '실험 설정(개발자용)'으로 접음 | 일반 사용자에게는 불필요한 조절 항목 | 기본값 = 실험으로 고른 설정 |

### 2. 운영 안정성 (배포 튜토리얼 1. 주의사항 · 4. 모니터링)

| 튜토리얼 항목 | 반영 내용 |
|---|---|
| 동시 접속자 수 | 업로드 파일을 **내용 해시별 폴더**에 저장 (2주차: 같은 파일명이면 다른 사람 파일을 덮어쓰고 이전 벡터DB를 재사용하는 버그). 벡터DB 캐시를 최근 6개로 제한해 메모리 폭증 방지 |
| 응답 속도 | 스트리밍, 임베딩 모델 · 벡터DB를 서버에서 한 번만 만들어 모든 접속자가 공유, 응답 시간 · 첫 글자 시간 표시 |
| 비용 관리 | **하루 API 비용 상한**(`DAILY_BUDGET_USD`, 기본 $2)과 **접속당 답변 수 상한**(기본 30회). 넘으면 멈추지 않고 오프라인 모드(검색 결과)로 전환 |
| 보안 | API 키는 Secrets/환경변수로만, `.env` · `secrets.toml`은 git 제외. 선택적 입장 코드(`APP_PASSWORD`), 오류 상세는 브라우저에 숨기고 로그에만 기록, 질문 길이 500자 · 업로드 20MB×3개 제한 |
| 모니터링 · 로깅 | 요청마다 JSON 로그 한 줄(모델 · 응답 시간 · 토큰 · 비용 · 오류 종류 · request_id, **질문 원문은 남기지 않음**). 앱 안의 📈 **운영 현황** 탭(질문 수, 평균/95% 응답 시간, 오늘 비용, 오류 수, 만족도) |
| 장애 대응 | Claude API 오류(키 · 과부하 · 네트워크) 시 안내 문구와 함께 **찾은 자료 원문으로 대체 응답**. 안전 분류기 거절 시 서버측 대체 모델(fallbacks) 사용 |

## 기술 스택

| 단계 | 예제 코드 | 이 프로젝트 |
|---|---|---|
| 문서 로드 / 분할 / 벡터DB | PyMuPDF / RecursiveCharacterTextSplitter / FAISS | 동일 + **BM25 색인**(rank-bm25, 한글 2글자 단위 토큰화) |
| 임베딩 | OpenAI Embeddings | `jhgan/ko-sroberta-multitask` (무료 로컬 한국어 모델) |
| 검색 | 유사도 검색 | **하이브리드**(BM25 + FAISS → RRF) + 대화 맥락 검색어 재작성 |
| LLM | GPT-4o | Claude Sonnet 5.5 (서비스 · 스트리밍) / Claude Haiku 4.5 (실험 · 검색어 재작성) |
| 프롬프트 | 영문 1줄 지시 | 기본(원본) / 개선(역할 · 형식 · Few-shot · 제약조건) |
| 화면 | 업로드 + 채팅 | + 스트리밍, 근거 · 응답 시간 · 비용 표시, 평가, 실험 결과 · 운영 현황 탭 |
| 배포 | - | Streamlit Community Cloud (+ 컨테이너용 Dockerfile) |

> `langchain-community`의 BM25 · Ensemble 리트리버는 패키지가 지원 종료(sunset) 예정이라,
> BM25와 RRF 결합은 `rank-bm25`로 직접 구현했습니다(`rag_module.py`의 `tokenize_ko`, `rrf_merge`).

## 로컬 실행

```powershell
# 1. 가상환경 생성 및 활성화
python -m venv venv
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
.\venv\Scripts\activate

# 2. 패키지 설치 (CPU 전용 torch가 함께 설치됩니다)
pip install -r requirements.txt

# 3. API 키 설정: .env.example 을 복사해 .env 로 만들고 Anthropic API 키 입력
copy .env.example .env

# 4. 실행
streamlit run app.py
```

처음 실행할 때 임베딩 모델(약 0.5GB)을 내려받으므로 1~2분 걸립니다.

> **오프라인 모드:** API 키가 없거나 `.env`에 `LLM_MODE=offline`이 있으면 API 없이 실행됩니다.
> 이때는 Claude 답변 대신 검색된 자료 원문을 관련도 순으로 보여줍니다.

### 환경변수

| 이름 | 기본값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | (필수) | Claude API 키. 없으면 오프라인 모드 |
| `ANTHROPIC_WORKSPACE_ID` | - | 워크스페이스에 묶이지 않은 키일 때만 |
| `APP_PASSWORD` | - | 설정하면 입장 코드를 맞혀야 사용 가능 |
| `DAILY_BUDGET_USD` | 2 | 하루(한국 시간) API 비용 상한. 넘으면 오프라인 모드 |
| `MAX_QUESTIONS_PER_SESSION` | 30 | 접속당 AI 답변 횟수 상한 |
| `LLM_MODE` | - | `offline`이면 오프라인 모드로 시작 |
